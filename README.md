# TechNova Solutions

Sitio web institucional desarrollado como proyecto final del curso de Desarrollo Web.

## Tecnologías utilizadas

- HTML5
- SCSS (SASS)
- Bootstrap 5
- JavaScript

## Características

- Diseño responsive.
- Navegación entre 5 páginas.
- Animaciones y transiciones.
- Sitio publicado en GitHub Pages y Netlify.
